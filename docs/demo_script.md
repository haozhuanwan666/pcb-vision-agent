## 0:00–0:06 开场封面

- **画面**：标题大图「🔍 PCB 缺陷智能检测平台」，副标题「基于 LangChain 视觉 Agent 的 3C 工件多缺陷智能检测系统」
- **旁白**：这是一个面向 3C 电子厂 PCB 外观检测的智能质检系统，融合传统机器视觉、YOLO 深度学习和 AI Agent 自主决策。
- **字幕建议**：传统视觉 + 深度学习 + AI Agent

---

## 0:06–0:18 单图检测（正常工件）

- **画面**：进入「单图检测」Tab → 拖入一张正常 PCB 图 → 点「开始检测」
- **操作**：
  1. 上传图片
  2. 保持「启用 Agent 智能决策」勾选
  3. 点击 🔍 开始检测
- **画面结果**：右侧显示「检测结果」图 + Markdown 报告（质量等级 good、缺陷 0、判定 合格）
- **旁白**：上传一张正常 PCB 图片，系统先自动评估图像质量，Agent 判断无异常后给出「合格」结论，整个过程不到一秒。

---

## 0:18–0:38 单图检测（缺陷工件 + Agent 决策）

- **画面**：切换到一张低对比度/含缺陷的 PCB 图 → 再次检测
- **画面结果**（关键镜头，可放大展示左侧报告）：
  - 图像质量：poor（低对比度、模糊）
  - Agent 决策过程：`assess_image_quality` → `enhance_contrast` → `yolo_detect` → 检出缺陷
  - 最终判定：**不合格**，异常图自动归档
- **旁白**：遇到低对比度的缺陷工件，Agent 不再固定一套参数——它自主评估出「低对比度」问题，先做对比度增强，再调用 YOLO 主检测，最后判定为不合格，并自动把异常图存档。这就是传统视觉做不到的自适应能力。
- **字幕建议**：质量评估 → 图像增强 → YOLO 检测 → 二次确认 → 生成报告

---

## 0:38–0:50 批量检测 + 报表

- **画面**：切到「批量检测」Tab → 输入图片文件夹路径 → 点「开始批量检测」
- **画面结果**：显示统计汇总（检测总数 / 合格 / 不合格 / 良率），并给出可下载的 Excel 报表
- **旁白**：批量检测一整个文件夹，系统自动统计良品率、按类别汇总缺陷，并生成带样式的 Excel 质检报表，不合格件自动留档，方便产线追溯。

---

## 0:50–0:58 性能与技术栈

- **画面**：切换到性能指标卡片/README 页面，展示：
  - mAP@0.5：96.6%　召回率：95.0%　漏检率：4.97%
  - 单图推理：~68ms　~14.7 FPS
  - 技术栈：Python / OpenCV / Halcon / YOLOv8 / LangChain / Gradio
- **旁白**：模型 mAP 96.6%，在 569 张验证集上召回率 95%、漏检率不到 5%；相比固定参数的传统视觉方案，漏检率降低约 95%，大幅减少人工调参。
